# 5일 교육 설계와 커리큘럼

## 확정 과정: 평일 5일 × 2시간 = 총 10시간

본인 노트북에서 코드 읽기를 중심으로 진행합니다. Oracle·MySQL을 비교하며 작은 코드 작성과 프로시저 전환은 디버거·로그로 확인합니다. 지정 교재는 없습니다. 아래 12회 상세 목록은 후속 학습 지도이며 필수 수업은 다음 5일 표입니다. 자율 실습은 선택 사항입니다.

| 일차 | 단계와 내용 | 120분 배분 | 완료 기준 |
|---|---|---|---|
| 1일 | 준비/초급: 수동 JDK·VS Code 설치, HelloWorld, 변수 | 목표 10 + 설치 50 + 실행 25 + 디버거 25 + 설명 10 | 실행과 중단점에서 변수 확인 |
| 2일 | 초급: 타입·null·BigDecimal, 분기·반복·메서드·클래스 | 개념 25 + 읽기 25 + 금액 검증 작성 35 + 디버깅 25 + 설명 10 | 입력→분기→반환/예외 추적 |
| 3일 | 중급: Boot 생성, HTTP, 어노테이션, Service·주입 | 개념 20 + 생성 30 + 읽기 25 + 로그/중단점 35 + 설명 10 | Controller→Service 호출 설명 |
| 4일 | 중급: Oracle/MySQL 비교, JDBC, DTO/List, SQL 바인딩 | 비교 20 + 읽기 30 + 조회 30 + 오류/로그 30 + 설명 10 | 바인딩·결과·SQL 위치 설명 |
| 5일 | 고급 입문: 예외·트랜잭션, 작은 전환과 비교 | 개념 20 + 대응표 25 + 실패 실험 35 + 평가 30 + 피드백 10 | 오류·롤백 경로를 근거로 설명 |

전달자는 교육 DB 접속·드라이버·초기 데이터를 수업 전에 준비합니다. 두 DB 의미를 비교하되 연결 실습은 준비된 DB 하나부터 진행합니다. DB가 준비되지 않으면 순수 Java 예제로 진행하고 DB 동작은 미검증으로 기록합니다. 두 DB 설치 전체를 10시간 수업에 포함하지 않습니다.

초급은 직접 읽기·작성, 중급은 호출 흐름 추적, 고급은 트랜잭션과 오류 흐름의 입문입니다. 스트림·JVM 튜닝·동시성 구현 등은 후속 학습입니다. 최종 제출은 읽기 메모, DB/Java 대응표, 정상·경계·실패 입력의 디버깅·로그 기록입니다.

## 도달 목표

학습자는 코드에서 입력·출력·분기·반복·SQL 실행·예외·트랜잭션 경계를 표시하고, 요청이 Controller → Service → Repository → DB로 이동하는 흐름을 설명합니다. 마지막에는 작은 프로시저의 업무 규칙을 Java로 옮기고 원본과 결과를 비교합니다. DBA 지식은 연결 고리로 사용하지만 DB 세션과 Java 객체, SQL NULL과 Java null은 동일한 개념으로 취급하지 않습니다.

## 교재 사용 방법

Java 입문서에서 흔히 사용하는 실행 환경 → 변수/자료형 → 연산자/제어문 → 배열 → 클래스 → 상속/인터페이스 → 예외 → 컬렉션 → 람다/스트림 → I/O/동시성 순서를 바탕으로 구성한 초안입니다. 실제 책이 정해지면 아래 연결표의 장·절을 채웁니다. Spring과 프로시저 변환은 교재 내용에 덧붙이는 별도 실습입니다.

| 단계·회차 | Java/교재 주제 | DBA 연결과 실습 | 완료 기준 | 교재 장·절 |
|---|---|---|---|---|
| 준비 1 | JDK/JVM, 컴파일·실행, 파일·패키지 | 직접 HelloWorld 작성, 컴파일, 중단점 | 소스→class→JVM 설명 및 실행 | 미정 |
| 초급 2 | 변수, 기본형/참조형, 연산자, String | NUMBER와 int/long/BigDecimal, NULL/null 비교 | 값의 타입·범위, 문자열 비교 설명 | 미정 |
| 초급 3 | if/switch, for/while, 배열, 메서드 | IF·루프·IN/OUT과 입력/반환 비교 | 30줄 코드 결과 예측, 메서드로 분리 | 미정 |
| 초급 4 | 클래스, 객체, 생성자, 접근제어, static | 주문 DTO, 인스턴스와 공유 상태 | 필드/지역변수 구별, 객체 생성 추적 | 미정 |
| 중급 5 | 인터페이스, 상속, 다형성, enum | 업무 규칙 구현 교체 | 인터페이스 호출의 실제 구현 찾기 | 미정 |
| 중급 6 | 예외, 컬렉션, 제네릭 | 행 목록→List, 키 조회→Map, 오류 전달 | null·빈 목록·예외 경로 설명 | 미정 |
| 중급 7 | 람다, 스트림, Optional, 날짜, BigDecimal | 합계·필터, 금액·시간 경계 | SQL 집계와 Java 처리의 차이 설명 | 미정 |
| 중급 8 | Spring Boot, DI, 어노테이션, HTTP/JSON | Controller/Service 분리, /hello 호출 | 주입·요청 매핑 흐름 추적 | 별도 자료 |
| 중급 9 | JDBC, 파라미터 바인딩, 리소스 관리 | JdbcTemplate으로 조회/갱신 | SQL·바인딩·영향 행 수 설명 | 교재 JDBC 장 + 별도 자료 |
| 고급 10 | 트랜잭션, 예외와 롤백, 테스트 | 두 갱신 중 두 번째 실패 | 원자성 확인, rollback 조건 설명 | 별도 자료 |
| 고급 11 | JVM/GC 기초, 스레드·공유 상태, I/O, 성능 | singleton 필드 위험, N+1 SQL, 락 | DB 시간/Java 시간 구별, 경쟁 상황 설명 | 미정 |
| 고급 12 | 업무 전환 종합 | 작은 프로시저 1개 변환·리뷰 | 결과·DB 변경·실패 시 동작 비교 | 별도 자료 |

고급은 이 교육의 업무 이해 기준입니다. JVM 튜닝, 고급 동시성 구현, 리플렉션·어노테이션 직접 제작은 선택 심화로 둡니다. 시간 부족 시 11회 심화를 줄이고 9~12회 검증 시간을 확보합니다.

## 단계별 읽기 질문

- 초급: 어디서 시작하는가? 변수에 어떤 값이 들어가는가? 분기 후 어떤 값을 반환하는가?
- 중급: 이 객체는 누가 만드는가? 인터페이스의 구현은 어디 있는가? null/빈 결과/예외는 어떻게 전달되는가?
- 고급: 트랜잭션은 어디서 시작하고 끝나는가? 실패 시 남는 변경은 무엇인가? 요청 두 개가 동시에 실행되면 안전한가?

## 후속 확장 과정의 실습과 평가

매 수업은 개념 20분 → 전달자의 코드 읽기 시연 20분 → 직접 실습 50분 → 학습자의 설명 20분 → 기록 10분으로 운영합니다. 자율 실습은 유사 문제·오류 재현·코드 읽기 기록으로 구성합니다.

단계마다 정상 입력, 경계값, 실패 입력을 준비합니다. 학습자는 실행 전 결과를 예측하고 디버거로 확인하며 틀린 이유를 기록합니다. 완료 기준은 암기나 코드 줄 수가 아니라 설명 가능한 호출 흐름과 검증 근거입니다.

최종 평가 산출물: 원본 의미 분석표, 전환 코드, 비교 테스트 결과, SQL 실행 횟수와 처리 시간, 남은 차이와 선택 이유. 전환 요소는 [별도 문서](conversion/01-elements.md)에 연결합니다.
